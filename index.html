Frequently Asked Questions

What is vibe kanban?
Vibe kanban is a workflow methodology where AI coding agents execute tasks in parallel while humans focus on planning, reviewing, and strategic oversight. Sciorex is the original implementation of vibe kanban for software development.
What is the ralph loop?
The ralph loop (Ralph Wiggum loop) is an iterative AI development technique where agents continuously work on tasks with progress persisting in git history rather than context windows. Sciorex fully supports this methodology.
Is Sciorex free?
Yes, Sciorex is completely free for personal and professional use. There are no subscriptions, no premium tiers, and no hidden costs. It is free forever.
Is Sciorex private?
Yes, Sciorex is 100% local. Your code and data never leave your machine. There is zero data collection, no telemetry, and no third-party APIs from Sciorex.
How is Sciorex different from Cursor?
Cursor is a paid standalone IDE ($20/month). Sciorex is a free wrapper that orchestrates your existing AI CLIs with vibe kanban, parallel agents via git worktrees, and visual workflows. Sciorex is 100% local with no data collection.
